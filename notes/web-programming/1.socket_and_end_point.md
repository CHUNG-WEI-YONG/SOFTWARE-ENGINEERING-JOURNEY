# Topic Name : Socket , end_point , io_context , acceptor

## 📌 Definition

### What is it?
- Socket : a place used to communicate and allow package sending and receiving between client and server , each connection both client and server has a socket
- End_point : an address that combine ip and also port number , it is the address of other side from this sides, for example client side has server address as end point but server has all ip address as endpoint 
- Io_context : a while loop place to help to write and read the information
- acceptor : socket at server side to listen to any connection to it   


---

## 🧠 Why do we need it?

Problem it solves.
Allow communication of client side and server side

---

## ⚙️ How it works

Step-by-step workflow.
| Client | Server |
|------|-------------|
| end_point | end_point(all ip_address) |
| socket | Acceptor socket |
| bind socket | bind socket |

        sock.connect(ep);

    }catch(system::system_error &e){
        std::cout<<"Error occur"<<std::endl;
    }
}

int dns_connect_to_end(){}

int accept_connect_to_end(){
    const int BLOCK_SZ=30;
    unsigned short port=3333;
    asio::ip::tcp::endpoint ep(asio::ip::address_v4::any(),port);
    asio::io_context io;
    try{
        asio::ip::tcp::acceptor acceptor(io,ep.protocol());
        acceptor.bind(ep);
        acceptor.listen(BLOCK_SZ);
        asio::ip::tcp::socket socket(io);
        acceptor.accept(socket);
    }catch(system::system_error &e){
        std::cout<<"Error";
    }
}
